The glitch, in three layers

1. Always on. The dark edge shadow flickers: a .12 second opacity animation.

2. Random. Every 5 seconds JavaScript gives the screen a class called fz for one second, 30% of the time.

3. Scripted. Lines in the story marked g trigger it when they start typing, like the word Michael.

.fz{filter:hue-rotate(40deg) brightness(1.25)}
.fz .tx{animation:jit .12s 8;
  text-shadow:3px 0 #f0f,-3px 0 #0ff}   /* RGB split */
@keyframes jit{20%{transform:translate(-6px,1px) skewX(2deg)}
  40%{transform:translate(6px,-1px)}}
The typing narrator

Every line of the story sits in an array with a colour and a pause. A function types it one letter at a time with setTimeout. Each run gets a number, so SKIP and REPLAY can cancel the old run instead of stacking two on top of each other.

const me = ++run;                 // this run's number
(function ch(){
  if (me !== run) return;           // cancelled? stop.
  if (k < t.length){ d.textContent = t.slice(0,++k);
    setTimeout(ch, 11); }
  else setTimeout(nextLine, pause);
})();

VOICE uses speechSynthesis.speak(). It sounds different on every device because it’s the browser’s own voice, not a recording.

The puzzle bits

Machine ID decoder. The ID uses only A–Z and 2–7, which is Base32. Each letter becomes 5 bits and the bits are regrouped into 8-bit bytes. The result reads blueshirt. The page shows every step, so you can type any other string.

bits += ALPHABET.indexOf(ch).toString(2).padStart(5,'0');
str  += String.fromCharCode(parseInt(bits.slice(i,i+8),2));

The grid game. The C++ code uses std::clamp to keep the character inside a 24 by 12 grid. I rebuilt that in JavaScript. Turn the clamp off on the main site and the @ walks off the grid.

x = Math.min(Math.max(nx, 0), W - 1);   // the wall

The power chart. One day is 2,684 kWh and the rest are about 25, so I used a log scale: bar height is log10(v+1) / log10(2700).

The pin board saves your theory in localStorage on your device only. Nothing is sent anywhere.

The honest bit

I built this with an AI assistant (Claude). It helped write and fix the code and gave ideas. The story, the look and each change were my decisions, and I’m happy to explain any part of it.

What I scrapped. My first version was a dark “hacker dashboard”. A review said it looked generic, so I rebuilt it as a desk with folders. I also tried comic panels for the story and cut them. The monitor won.

What I’d add with more time. A real database so judges’ theories show for everyone, recorded voice acting instead of the browser voice, and a proper case-file PDF.
