##  The Lore & Mission
Agent **Dev G.** and Agent **Viv S.** are on a high-stakes mission to uncover the truth behind **Case: The Reckoning V: Origins**. Dive into the interactive experience to see how the investigation unfolds—check out the website to find out what happens next!


##  Key Features
* **Voice Narrated Story:** Immersive audio-driven storytelling that brings the narrative to life using the Web Speech API.
* **Interactive UI:** Dynamic elements and smooth user flows to keep you hooked on the mystery.


## Tech Stack
Built with a robust and modern frontend stack:
* **Markup & Styling:** HTML5, CSS3, Google Fonts
* **Interactivity & APIs:** JavaScript, Web Speech API, SVG graphics
* **Hosting & Deployment:** Vercel
